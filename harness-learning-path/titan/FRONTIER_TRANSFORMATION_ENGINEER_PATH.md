# 1. Where This Path Starts

21-day sprint đã chuẩn bị ba foundational certification areas:

```text
AI-103
Azure AI Apps and Agents Developer Associate
        +
GH-300
GitHub Copilot
        +
AB-100
Agentic AI Business Solutions Architect
        ↓
FOUNDATIONAL CERTIFICATION LAYER
```

Microsoft Partner hiện mô tả Frontier Transformation Engineer badge là một **individual delivery-readiness credential**, không chỉ là một exam badge.

Badge kết hợp:

1. foundational certifications;
2. hands-on Project Ready learning and assessments;
3. delivery-pattern fluency.

Official foundational certification areas currently listed by Microsoft Partner:

- GH-300 — GitHub Copilot
- AI-102 or AI-103 — Develop AI apps and agents on Azure
- AB-100 — Agentic AI Business Solutions Architect

Với path hiện tại, dùng **AI-103**, không quay lại AI-102.

# 7. Phase C — Center of Excellence (CoE)

Microsoft Partner explicitly lists Center of Excellence pattern fluency as part of Frontier badge readiness.

A Frontier CoE is not just a governance committee.

Think:

```text
Enterprise AI Portfolio
      ↓
Standards
Patterns
Security Baseline
Agent Registry
Evaluation Baseline
Reusable Components
Delivery Playbooks
Adoption / Measurement
```

## CoE questions you should answer

- Who can create/publish agents?
- What security baseline is mandatory?
- How are agents registered and owned?
- Which evaluation thresholds block deployment?
- Which patterns are reusable?
- How are model/tool/agent versions tracked?
- How is cost monitored?
- How are incidents escalated?
- How are lessons reused across projects?

# 8. Phase C — Hypervelocity Engineering (HVE)

Microsoft Partner identifies Hypervelocity Engineering as a delivery pattern for Frontier Transformation.

Public Partner material also describes an HVE deep dive as a **credit-required session for the Frontier Transformation Engineer badge** in the Summit context.

Treat HVE as a delivery operating model for moving from idea to production quickly while retaining engineering controls.

Working mental model:

```text
Business Problem
   ↓
Fast Discovery
   ↓
Prototype / Live Build
   ↓
Tight User Feedback
   ↓
Production Hardening
   ↓
Governance / Security
   ↓
Scale / Reuse
```

Do not interpret "hypervelocity" as skipping architecture, security, testing, or governance.

The point is shortening feedback loops and using repeatable patterns.

# 10. Our Post-Cert Study Sequence (NOT official course titles)

The following sessions are our preparation sequence. They must not be confused with the official 11 Titan courses.

## T1 — Frontier Operating Model

Study:

- what Frontier Transformation means;
- agent-powered operating capability;
- identity, security, compliance, monitoring, change management;
- difference between pilot and operating capability.

Output: Frontier capability map.

## T2 — Project Ready Architecture Workshop

Use one real scenario and create:

```text
Outcome
 ↓
Architecture
 ↓
Agent / Copilot selection
 ↓
Data / Tools
 ↓
Security / Governance
 ↓
Deployment
```

Output: customer-ready architecture pack.

## T3 — Project Ready Implementation Simulation

Simulate:

- environment setup;
- agent/tool configuration;
- grounding;
- permissions;
- test/eval;
- approval;
- deployment;
- operational handover.

Output: implementation runbook.

## T4 — Center of Excellence Workshop

Build:

- agent registry policy;
- risk tiers;
- security baseline;
- evaluation gate;
- reusable pattern catalog;
- ownership/RACI.

Output: Frontier CoE starter pack.

## T5 — Hypervelocity Engineering Workshop

Run a compressed build cycle:

```text
Discover → Prototype → Validate → Harden → Ship → Learn
```

Capture:

- feedback loops;
- architecture decisions;
- quality gates;
- security gates;
- reusable artifacts.

Output: HVE delivery playbook.

## T6 — Badge Readiness Audit

Check:

- all required certifications recorded;
- all required Project Ready modules completed;
- required assessments passed;
- HVE/CoE/industry-pattern credits complete;
- profile/tenant association correct;
- missing requirements documented from Partner Skilling Hub.

Output: completion matrix.
