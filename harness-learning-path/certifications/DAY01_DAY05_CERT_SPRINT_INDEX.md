# 3. Learning Rhythm

For each day:

```text
1. Read / listen to one module
2. Explain it back by voice
3. Answer scenario question
4. Correct mental model
5. Continue to next module
6. Finish oral checkpoint
7. Mark PASS or REVIEW
```

Do not read all content passively in one sitting.

The files are designed to be used as scripts for live voice learning.

# 5. What Is Deliberately Deferred

The first five days are primarily conceptual/exam preparation.

Deferred to the four integrated hands-on sessions:

- real model/API calls;
- actual MCP server/client setup;
- code-based RD Parser Agent;
- multi-agent workflow implementation;
- GitHub Copilot-assisted implementation;
- tests/evaluation pipeline.

Reason:

> First establish correct architecture vocabulary and mental models, then use hands-on work to prove them.
