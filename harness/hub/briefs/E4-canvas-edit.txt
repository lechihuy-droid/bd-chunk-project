      2. `yaml.safe_dump(model, sort_keys=False, allow_unicode=True, default_flow_style=False)`.
         `allow_unicode=True` là BẮT BUỘC — prompt và comment có tiếng Việt, thiếu nó sẽ thành `\uXXXX`.
      3. Ghép: khối comment + YAML mới.
      4. Đưa chuỗi đó qua `workflow.save_workflow(id, yaml_text)` — KHÔNG tự ghi file. save_workflow đã lo
         parse + validate + kiểm id khớp + backup.
      5. Validate lỗi -> 400 kèm danh sách lỗi, KHÔNG ghi gì cả.
    - Vì sao sinh YAML ở server: prompt nhiều dòng cần block scalar, escape, quote. Tự sinh bằng TS dễ sai
      âm thầm. PyYAML đã đúng sẵn.
