SCOPE — /chat (Chat đa cửa sổ):
1. Pane model: array of panes in React state, persisted to localStorage key
   "hub-v3-chat" (panes: id, provider, model, title, messages[], cliSessionId).
   Buttons: "+ Cửa sổ" (add pane, pick provider from GET /api/providers — show
   unavailable providers disabled with detail tooltip), "×" close pane.
   Layout: CSS grid, 1 pane = full, 2 = 1x2, 3-4 = 2x2. Max 4 panes.
2. Pane head: provider color dot (token colors --claude/--codex/--nvidia/--gemini),
   provider id + model short name, cliSessionId tail (last 8 chars) when present,
   badge: "READ-ONLY" for claude/codex/gemini, "FREE" for nvidia (mono 10px pill).
3. NVIDIA panes: model selector <select> from /api/chat/models catalog (group by
   category, default from payload.default). claude/codex panes: model field free-text
   optional (placeholder "mặc định").
4. Send flow: POST /api/chat via fetch + ReadableStream SSE parse (write a small
   src/lib/sse.ts parser: split on double newline, "event:"/"data:" lines, JSON data).
   Stream: reasoning text -> collapsible dim "thinking" block (hidden by default,
   toggle per message); delta -> append to live plain-text bubble; done -> finalize
   message, store session_id into pane.cliSessionId (next send passes it back =
   multi-turn CLI resume), record usage line under message (mono 10px: model ·
   tokens if present); error -> red inline system bubble with message.
   Stop button while streaming (AbortController.abort()).
5. Multi-turn payload rule: for nvidia send FULL messages history each time;
   for claude/codex when cliSessionId exists send ONLY the new user message
   (CLI resumes context) — else full history. Comment this rule in code.
6. Markdown render ON DONE ONLY (streaming shows plain text): write
   src/lib/markdown.tsx that builds React elements directly (NO raw HTML, NO
   dangerouslySetInnerHTML, no new deps): support #/##/### headings, **bold**,
   *italic*, `inline code`, ``` fenced code blocks (mono, panel bg, Copy button),
   -/* lists, [text](http/https links only, target_blank rel noopener), paragraphs.
   Everything else = plain text. Escape-first mindset: unknown syntax renders literally.
7. Broadcast: checkbox "Gửi tất cả" next to a shared composer at top; when on,
   the shared composer sends the same prompt to every pane in parallel (each pane
   keeps its own per-pane composer too).
8. Per-pane actions: "Xuất .md" (download transcript as markdown file via blob),
   "Xoá" (clear messages, keep provider), copy button per message.
