1. PHÂN LOẠI TRẠNG THÁI PROVIDER — suy từ `available` + `detail`, KHÔNG hardcode theo tên provider:
   - available true                       -> "sẵn sàng"
   - available false + detail chứa "not set" / "not configured" / tên biến môi trường -> "chưa cấu hình"
   - available false + detail "not_installed"                                          -> "chưa cài"
   - available false, còn lại                                                          -> "không khả dụng"
   Mỗi trạng thái một màu khác nhau (dùng token có sẵn: --ok/--gate/--err/--faint). Hiện `version` khi có.

2. ERROR CARD trong pane khi gửi thất bại (thay cho dòng chữ đỏ trơ trọi hiện nay):
