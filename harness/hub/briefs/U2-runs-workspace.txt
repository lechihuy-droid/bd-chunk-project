BACKEND API (all EXISTS — confirmed; use exactly these, change none):
- GET  /api/workflows                                  -> [{id, ...}] list to choose a workflow to run.
- POST /api/workflows/validate   {id}                  -> {ok, errors, ir}. ir = ordered node list, each
    node has at least {id, gate, order} (+ agent, prompt). USE ir TO DRAW THE FULL SPINE SKELETON upfront
    (all nodes pending), before/at run start. (POST → api.ts adds X-Hub-Client header automatically.)
- POST /api/workflows/{workflow_id}/runs   {objective} -> SSE stream (text/event-stream). Drives the run.
- GET  /api/agent/runs                                 -> list of ALL runtime runs (workflow runs included):
    each = run state {run_id, status, thread_id, metadata:{objective, node_index, completed_nodes,
    node_outputs, current_node, updated_at, ...}}. USE for the "recent runs" list to reopen a run.
- GET  /api/agent/runs/{run_id}                        -> full run state (reopen).
- GET  /api/agent/runs/{run_id}/events                 -> events.jsonl as list (reopen a finished/paused run).
- POST /api/workflows/runs/{run_id}/interrupts/{interrupt_id}/resume  {approved:bool, ...} -> SSE continues.
    (For a gate: Approve sends {approved:true}; Reject sends {approved:false}. Confirm payload against how
     runtime resolves it — the run stream at a gate creates an interrupt then ENDS; resume continues it.)
- GET  /api/workflows/runs/{run_id}/artifacts          -> {"artifacts":[{name, chars}]}  (D1, node .md files).
- GET  /api/workflows/runs/{run_id}/artifacts/{name}   -> {"name", "text"}  (full node output markdown).

SSE EVENT CONTRACT (events emitted by the run stream — map each to spine/rail):
  assistant_delta {node, text}  -> append to that node's live output (plain text while streaming).
  reasoning       {node, text}  -> that node's collapsible dim "thinking" (append, hidden by default).
  node_update     {...}         -> node status transition (refresh node state from snapshot).
  state_snapshot  {state}       -> authoritative full state; recompute spine node states from
                                    metadata.node_index / completed_nodes / current_node / node_outputs.
  artifact_written{node, path, chars} -> mark node "has artifact"; refresh the Artifact tab list.
  interrupt       {...}         -> a GATE is waiting: render the amber diamond node + inline Gate card
                                    (objective/prompt) with Approve / Reject. Stream ENDS here.
  done            {status, state} -> finalize run (succeeded/failed); stop spinner.
  error           {message, ...}  -> red inline error on the node/run.
